# 🏙️ Hack-N-Dore 2K24 – IMC Asset Management Portal

**Team: CodeCadets**

Welcome to the official website prototype for the **Indore Municipal Corporation (IMC)** created for **Hack-N-Dore 2K24**.
This portal helps IMC employees manage city assets, track maintenance, and improve public services.

## 🔍 Project Name: AssetAid

A smart and simple tool to:

* Track and manage public vehicles (buses, cars, garbage trucks, etc.)
* Schedule maintenance and record service history
* Make asset data easy to filter, view, and update

## 🛠️ Built With

* **HTML**
* **CSS**
* **JavaScript**

## 💡 Key Features

### 📦 Asset Management

* Filter assets by category (Bus, Car, Garbage Truck, Other)
* View details: Type, Number, Route No., Condition, Service Date
* Add new assets using a form
* Automatically updates the table when new data is added

### 🛠️ Maintenance Tracker

* Input vehicle service info
* Calculates next service date automatically
